# PULSE

パーソナルトレーニング用の心拍モニター。Polar H10 などの心拍センサーから Web Bluetooth（Heart Rate Service 0x180D / Heart Rate Measurement 0x2A37）で心拍を受信し、PC の大きな画面に表示します。

- 静的 HTML / CSS / JavaScript のみ（ビルド不要・外部通信なし・外部フォントなし）
- 記録はブラウザ内の IndexedDB にのみ保存（サーバーや GitHub には送信しません）
- 対応ブラウザ：Mac の Google Chrome（Safari・Firefox は Web Bluetooth 非対応）

## 使い方

1. 「新規登録」で顧客（氏名・年齢・メモ）を登録して選択
2. 運動前：年齢／測定済み最大心拍／普段の安静時心拍を設定。落ち着いた状態で「直近10秒の平均を登録」
3. 「H10に接続」→ H10 を選択（デモで動作確認も可。デモ記録は実測と区別して保存）
4. 運動中：セット終了時に「セット終了・回復を測る」
5. 回復：回復方法・種目・重量・回数を入力 → 60秒（最大120秒）経過後「記録して終了」
6. 結果：セッション推移、回復記録、同条件の比較、CSV。「セッションを終了」で確定

バックアップ（JSON）と復元は画面上部から。旧サイト（pulse-v2）のバックアップ JSON も復元できます。

## 計測の定義

- 受信が5秒以上途絶えたら現在値を表示しない。5秒を超える間隔は欠測としてグラフを途切れさせる
- 回復の30／60／120秒値：各時刻の ±2秒以内の実測値のみ。範囲内に実測がない場合は「測定不足」、途中に5秒超の欠測があれば「無効」とし比較に使わない
- 同条件：同じ顧客・回復方法・種目・重量・回数・データ種別（実測／デモ）。種目未入力は比較しない
- 強度の目安：ACSM の %最大心拍区分（<57 / 57–63 / 64–76 / 77–95 / ≥96 %）。生理学的閾値ではない
- 推定最大心拍：208 − 0.7 × 年齢（Tanaka 式）
